# Contribution workflow

- [ ] Read `CONTRIBUTING.md` and project-specific instructions.
- [ ] Search existing issues and pull requests to avoid duplicates.
- [ ] Confirm the issue is still open and suitable for a beginner.
- [ ] Ask for clarification or assignment if the project expects it.
- [ ] Reproduce the bug or understand the requested behavior.
- [ ] Write down expected vs actual behavior.
- [ ] Create a focused branch with a descriptive name.
- [ ] Make the smallest reasonable change.
- [ ] Add or update tests.
- [ ] Run formatting, linting, type checks, and relevant tests.
- [ ] Review the diff; remove debug code and unrelated changes.
- [ ] Write a clear PR description with testing evidence.
- [ ] Respond constructively to review comments.
- [ ] Update this repository's PR log after submitting.
